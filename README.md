# 🎙️ Application 07 - Speech to Text

## 📌 Aim

To convert spoken words into written text using JavaScript Speech Recognition.

## 📝 Description

Speech-to-Text is a speech processing technology that converts human speech into text.

This application uses the browser's built-in Speech Recognition API to recognize the user's voice.

## ✨ Features

- 🎤 Voice recognition
- 📝 Real-time text conversion
- 📋 Copy text
- 🗑️ Clear text
- 🎨 Modern user interface
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API

## ⚙️ How It Works

1. Click **Start Speaking**.
2. Allow microphone permission.
3. Speak clearly.
4. The application converts speech into text.
5. Click **Copy** to copy the generated text.

## 💡 Example

### Speech

Hello, I am learning Text and Speech Analysis.

### Output

Hello, I am learning Text and Speech Analysis.

## 🌐 Application

Speech-to-Text technology is used in:

- Voice assistants
- Dictation systems
- Accessibility tools
- Transcription systems
- Voice search
- Chat applications

## ⚠️ Note

Speech Recognition support depends on the browser and device.
